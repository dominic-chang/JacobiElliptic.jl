Algorithm Selection

Every function below dispatches to a default algorithm. Pass an JacobiElliptic.AbstractAlgorithm instance as the first argument to choose one explicitly, for example F(Carlson(), φ, m) or K(Fukushima(), m).

JacobiElliptic.default_algorithm — Function
default_algorithm() -> AGM

default_algorithm() -> AGM

Return the algorithm currently used when none is passed explicitly. Defaults to AGM, which supplies the complete K and E and delegates everything else to Carlson. Change it with set_default_algorithm!.

source
JacobiElliptic.set_default_algorithm! — Function
set_default_algorithm!(
    alg::JacobiElliptic.AbstractAlgorithm
) -> JacobiElliptic.AbstractAlgorithm

set_default_algorithm!(
    alg::JacobiElliptic.AbstractAlgorithm
) -> JacobiElliptic.AbstractAlgorithm

Set the process-wide default algorithm and return it. Accepts an instance or the type itself, so set_default_algorithm!(Fukushima()) and set_default_algorithm!(Fukushima) are equivalent.

Intended for configuration at startup.

source
JacobiElliptic.AbstractAlgorithm — Type

Supertype for the algorithms used to evaluate the elliptic integrals and Jacobi elliptic functions. Pass an instance as the first argument to select one explicitly, e.g. F(Carlson(), φ, m).

source
JacobiElliptic.AGM — Type

Arithmetic-geometric mean algorithm. Defined only for the complete integrals K(m) and E(m), for which it is the default.

source
JacobiElliptic.Carlson — Type

B. C. Carlson's symmetric-form algorithms, built on the DRF, DRD and DRJ duplication routines. This is the default for every function other than the complete K and E.

source
JacobiElliptic.Fukushima — Type

Toshio Fukushima's algorithms. Available for every function in JacobiElliptic except the complete integrals' AGM forms, and the only algorithm providing asn and acn.

source

Complete elliptic integral of the first kind. Defaults to AGM.

source
JacobiElliptic.E — Function

$E(m) = \int_0^{\pi/2}\sqrt{1-m\sin^2\theta}\,d\theta$ and $E(\varphi|m) = \int_0^{\varphi}\sqrt{1-m\sin^2\theta}\,d\theta$

Complete and incomplete elliptic integrals of the second kind. The complete form defaults to AGM, the incomplete form to Carlson.

Arguments

  • φ : Amplitude (incomplete form only)
  • m : Elliptic parameter
source
JacobiElliptic.F — Function

$F(\varphi|m) = \int_0^{\varphi}\frac{d\theta}{\sqrt{1-m\sin^2\theta}}$

Incomplete elliptic integral of the first kind. Defaults to Carlson.

Arguments

  • φ : Amplitude
  • m : Elliptic parameter
source
JacobiElliptic.Pi — Function

$\Pi(n|m)$ and $\Pi(n;\varphi|m) = \int_0^{\varphi}\frac{d\theta}{(1-n\sin^2\theta)\sqrt{1-m\sin^2\theta}}$

Complete and incomplete elliptic integrals of the third kind. Defaults to Carlson. For $n > 1$ the result is the Cauchy principal value.

Arguments

  • n : Characteristic
  • φ : Amplitude (incomplete form only)
  • m : Elliptic parameter
source
JacobiElliptic.J — Function

$J(n|m)$ and $J(n;\varphi|m)$, the associate elliptic integral of the third kind, related to $\Pi$ by $J = (\Pi - F)/n$. Defaults to Carlson.

Arguments

  • n : Characteristic
  • φ : Amplitude (incomplete form only)
  • m : Elliptic parameter

Internals

Not part of the public API — documented because the GPU extensions depend on them, and they may change without a breaking release.

JacobiElliptic.AlgorithmCall — Type

A callable binding f to alg, so that AlgorithmCall(f, alg)(args...) is f(alg, args...). Used by GPU backends, which need a concrete function to compile.
